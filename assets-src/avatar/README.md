# Avatar de Edgar

Ilustraciones de Edgar en estilo cómic (sudadera negra, gafas), con fondo transparente (WebP).
Esta carpeta **no se publica**: para usar una en la web, copia una versión optimizada
(máx. 480 px) a `public/` y pídele antes el visto bueno a Edgar.

`catalogo-avatar.webp` las muestra todas con su nombre.

- dudando
- enojado
- pulgar-arriba
- riendo
- sorprendido
