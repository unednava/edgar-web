# Avatar de Edgar

Ilustraciones de Edgar en estilo cómic (sudadera negra, gafas). PNG con fondo transparente,
1024 × 1024, todas con el mismo encuadre. Esta carpeta **no se publica**: para usar una en la web,
copia una versión optimizada (máx. 480 px) a `public/` y pídele antes el visto bueno a Edgar.

`catalogo-avatar.webp` las muestra todas con su nombre (sobre fondo oscuro, para ver el borde).

**Borde limpio:** las imágenes originales traían un halo blanco fino alrededor (se notaba sobre
fondos oscuros, como en un stream). Se corrigió recalculando la transparencia del borde y
oscureciendo esos píxeles hacia la línea negra del dibujo. No se tocó nada del interior.

## Expresiones

- dudando
- enojado
- pulgar-arriba
- riendo
- sorprendido

## pngtuber/

Dos juegos con el mismo dibujo y el mismo encuadre: `con-mano/` (mano levantada, como explicando)
y `sin-mano/` (brazos abajo, más neutro). En cada juego solo cambia la boca (y un poco la mandíbula
y las cejas), así que se pueden alternar sin que el personaje salte. Para un programa de PNGTuber
(Veadotube, PNGtuber Plus…), en cada juego:

- **En silencio:** `boca-cerrada.png`
- **Hablando:** `hablando.png` (o alternar `hablando` y `hablando-fuerte` según el volumen)
- `boca-o.png`: sorpresa breve o la vocal "o"

Los dos juegos también comparten encuadre entre sí: se puede pasar de uno a otro (por ejemplo,
levantar la mano al explicar algo) sin que la cabeza se mueva.
