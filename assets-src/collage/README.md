# Biblioteca de recortes de collage

Piezas recortadas (fondo transparente, WebP) de las láminas de collage de Edgar.
Esta carpeta **no se publica**: para usar una pieza en la web, copia una versión
optimizada (máx. 480 px) a `public/collage/` y úsala con la clase `.cutout`
(ver CLAUDE.md, "Collage, solo toques").

Cada `catalogo-lamina-N.webp` muestra todas las piezas de esa lámina con su nombre.

**Licencia:** Edgar indicó que tiene licencia de las láminas. Se dejaron fuera tres piezas
que traían **marca de agua de bancos de imágenes** (señal de que no estaban compradas):
el fajo de billetes ("envato") y el globo con avión y cajas ("123RF") de la lámina 2, y la
placa "Area 51" ("pngtree") de la lámina 3. No recuperarlas sin una versión con licencia.
La Mona Lisa y las manos de "La creación de Adán" son obras de dominio público.
